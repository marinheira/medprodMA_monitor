# Росздравнадзор: Netlify-версия

## Возможности
- несколько торговых наименований через кнопку `+`;
- даты по умолчанию: последние 7 дней;
- формирование одного XLSX;
- отдельная колонка `Поисковый запрос`;
- полный текст из `title`, если он доступен.

## Deploy from Git
1. Создайте новый GitHub/GitLab репозиторий и поместите в него содержимое этой папки.
2. В Netlify выберите **Add new project → Import an existing project**.
3. Build command и publish directory будут прочитаны из `netlify.toml`.
4. Запустите deploy.

## Локальный тест
```bash
npm install
npm run dev
```

## Ограничение архитектуры
Экспорт выполняется одной синхронной Netlify Function. Очень широкие даты и большое число препаратов могут превысить лимит времени функции. Для таких выгрузок используйте локальную desktop-версию либо переводите обработку на фоновую функцию с внешним хранилищем.
